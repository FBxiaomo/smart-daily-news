# 新闻类型、来源与匹配规则

内置分类将可选兴趣按要闻与社会、科技与数码、汽车与产业、商业与经济、科学与环境、
生活与兴趣分组。每个分类列出可用来源和匹配关键词；用户可同时选择多项。
`TOPICS` 中的 `id` 是稳定键，`name`、`group` 和 `description` 用于界面。
`SOURCES` 是来源目录；`build_sources(selected_ids)` 只添加所选类别需要的订阅源，同一个 RSS 只抓取一次。

已提供中文内容为主的国内、国际、社会、法治、地方、科技、AI、手机硬件、软件开发、
网络安全、游戏、汽车、智能驾驶、能源、财经、证券市场、企业、创业、房产、
科学、航天、环境、健康、教育、文化、影视、体育、旅行及日常消费等类别。
BBC 和 NASA 相关分类提供补充信息；原文可能为英文。通过 AI 生成的摘要语言与原始标题语言可以不同。

## 某篇新闻如何归类

1. 仅在用户选定的类型中判断，返回所有匹配项；多个类型是“任一匹配”。
2. 对所选类型的明确垂直 RSS，文章直接归类。例如中新网体育频道的文章可归为“体育与赛事”。
3. 综合源（例如 IT之家、36氪、少数派）先检查该源是否在该类型的候选来源中，
   再匹配该类型的中文/英文关键词。选择“汽车”不会因为 IT之家同时报道汽车和手机而包含纯手机新闻。
4. 用户自定义的 RSS 不限定预设 source ID，但也要匹配选中类型的关键词；不能无条件放进每个类别。
5. 每个类型可额外传入用户自己的关键词（`extra_keywords`）；它们与该类型内置关键词按“任一命中”处理。
6. 没有选类型或者一篇文章没有命中，就不返回该篇的主题；没有新闻时按正常空结果处理，不填充示例。

分类匹配可调用：

```python
from daily_news.topics import build_sources, match_topics

selected = ["ai", "automotive"]
feeds = build_sources(selected)
topics = match_topics("汽车搭载人工智能芯片", "", "ithome", selected)
# topics == ["ai", "automotive"]
```

匹配是透明的字词规则，不等于模型语义理解或事实判断；术语、新品牌、同义词未收录时可能漏报，
语境相近时也可能误判。添加用户关键词可改进覆盖。英文关键词有单词边界，避免将 `said` 误认为 `AI`。
若主程序同时设置全局 `include_keywords` / `exclude_keywords`，它们应与类型选择分开说明：
分类中的多个类型以 OR 合并，用户另设的全局包含/排除条件再对候选文章过滤，不将所有类型做交集。

## 内容来源情况

2026-10-27 只读检查了候选源：IT之家、Solidot、少数派、36氪、BBC 对应 RSS、
NASA 新闻，以及中新网国内、国际、社会、财经、生活、文娱、体育、教育、法治频道均可解析且当时有近期内容。
来源可能随时更改地址、限制访问、更新频率或停止维护，成功一次不能保证今后可用。
采集器会报告失败；栏目短期无稿件不会虚构新闻。

中新网官方公开的部分旧 RSS 虽能返回 200，但健康源当时停在 2026-03，旧汽车源停在 2026-08，
因此没有列入默认候选。健康类别可用 BBC Health 和综合中文来源的关键词匹配；
汽车类别从综合来源筛选，不表示具备完整的专业汽车新闻覆盖。
可以为主题添加自己的真实 RSS/Atom 来源或授权商业新闻源，进一步改善内容质量。

公开订阅地址并不自动授予面向商业用户再分发内容的许可。
商业使用请依据所选来源许可或取得授权，并保留来源署名与原文链接。
