📰 Smart Daily News

English | 中文说明

🚀 Introduction
Smart Daily News is a lightweight, intelligent news aggregation and summarization tool designed to help you cut through the information overload. It automatically curates trending topics from various sources and uses AI to generate concise summaries, delivering a personalized daily briefing straight to you.

✨ Features
🌐 Multi-Source Aggregation: Automatically fetches trending news from multiple platforms (e.g., Hacker News, RSS Feeds, Social Media Trends).
🤖 AI-Powered Summarization: Leverages Large Language Models (LLMs) to distill lengthy articles into clear, actionable bullet points.
🔔 Scheduled Delivery: Supports automated daily push notifications via Email, Telegram, or WeChat.
⚡ Easy Deployment: Built with Python, featuring a simple install.py for quick setup on local machines or servers.

🛠️ Quick Start

bash
Clone the repository
git clone https://github.com/your-username/Smart-Daily-News.git

Install dependencies
python install.py

Run the application
python main.py
